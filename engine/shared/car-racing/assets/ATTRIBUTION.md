# Asset attribution

The game code is a simplified version of Playtura's games-library Car Racing (`packages/games/src/games/car-racing`). The car and tree models are built procedurally in TypeScript; no model files are used.

`textures/asphalt.png`, `textures/grass.png` and the WAV effects in `sfx/` are copied from `packages/games/src/assets/textures` and `packages/games/src/assets/sfx` in the Playtura checkout.
