# Nayan UI - Component Library & Developer Tools

## Project Overview
Nayan UI is a comprehensive, enterprise-grade UI component library for React and React Native applications, plus a full suite of 50+ free online developer tools. It provides 58 documented components — 35 for React and 23 for React Native — with TypeScript-first development, CSS-variable theming, and cross-platform compatibility.

**Website**: https://www.nayanui.com
**Repository**: https://gitlab.com/ursnj/nayan-ui
**License**: ISC

## Architecture
- **Monorepo Structure**: Yarn workspaces
- **Packages**:
  - `@nayan-ui/react` — React components built on HeroUI + Tailwind CSS
  - `@nayan-ui/native` — React Native components with NativeWind
  - `@nayan-ui/cli` — CLI tools for SEO (sitemap, robots.txt generation)
  - `@nayan-ui/ai` — AI-powered code reviewer & vulnerability scanner CLI
  - `@nayan-ui/tools` — Tools library (video editor, PDF tools, image tools, JSON tools, XML tools, text tools)
  - `@nayan-ui/website` — Next.js documentation website (this site)

## Technology Stack
- **Website**: Next.js 15, React 19, TypeScript, Tailwind CSS v4, HeroUI
- **React Package**: React 19, TypeScript, HeroUI, Tailwind CSS, Vite
- **React Native**: React Native 0.80+, NativeWind, Expo SDK 53+
- **Build Tools**: Vite, Next.js, react-native-builder-bob, TypeScript
- **Styling**: Tailwind CSS, HeroUI design tokens, CSS variables for theming
- **Icons**: Lucide React (React), Lucide React Native (React Native)
- **Development**: Yarn workspaces, Husky, Prettier

## Component Categories

## Theme Configuration

### React Theme Setup
```typescript
import { NTheme, THEMES } from '@nayan-ui/react';

const themeColors = {
  light: {
    primary: '#3b82f6',
    background: '#ffffff',
    foreground: '#0f172a'
  },
  dark: {
    primary: '#60a5fa',
    background: '#0f172a',
    foreground: '#f8fafc'
  }
};

function App() {
  return (
    <NTheme theme={THEMES.light} themeColors={themeColors}>
      {/* Your app content */}
    </NTheme>
  );
}
```

### React Native Theme Setup
```typescript
import { NTheme, THEMES, useNTheme } from '@nayan-ui/native';

export default function App() {
  const { theme } = useNTheme();
  
  return (
    <NTheme theme={theme || THEMES.light} themeColors={themeColors}>
      {/* Your app content */}
    </NTheme>
  );
}
```

## Component Usage Patterns

### Basic Component Usage
```typescript
import { NButton, NInput, NCard } from '@nayan-ui/react';

function MyComponent() {
  return (
    <NCard>
      <NInput placeholder="Enter text" />
      <NButton variant="default" size="md">
        Submit
      </NButton>
    </NCard>
  );
}
```

### Advanced Theming
```typescript
import { NButton } from '@nayan-ui/react';

function CustomButton() {
  return (
    <NButton 
      variant="outline"
      className="bg-gradient-to-r from-blue-500 to-purple-600 text-white border-none"
    >
      Custom Styled Button
    </NButton>
  );
}
```

### Form Integration
```typescript
import { useForm } from 'react-hook-form';
import { NFormInput, NButton } from '@nayan-ui/react';

function ContactForm() {
  const { control, handleSubmit } = useForm();
  
  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <NFormInput
        control={control}
        name="email"
        label="Email"
        rules={{ required: 'Email is required' }}
      />
      <NButton type="submit">Submit</NButton>
    </form>
  );
}
```

## Video Editor

**Page**: https://www.nayanui.com/video-editor
**App**: https://www.nayanui.com/video-editor/start
**Source**: https://gitlab.com/ursnj/nayan-ui

A free, open source (MIT) video editor that runs entirely in the browser. There is no server, no account, no upload step and no watermark: media is opened from disk, decoded, composited and encoded on the user's own machine using WebCodecs, and the export is written straight to their downloads folder. It works offline once the page has loaded.

### Capabilities
- **Timeline**: unlimited video and audio tracks; drag, trim, split at the playhead, ripple delete, multi-select, grouping, copy/cut/paste, detach audio, snapping, in/out range marking, undo/redo
- **Colour**: 15 named looks each with a strength dial, plus a manual grade — brightness, contrast, highlights, shadows, fade, saturation, vibrance, temperature, tint, split toning, sharpen, vignette, grain, blur
- **Green screen**: GPU chroma key with similarity, edge softness and spill removal, keyed on chrominance
- **Transitions**: 18 — dissolve, blur dissolve, dip to black/white, wipes and slides on four edges, pushes, zoom in/out, whip pan, iris
- **Text**: title/subtitle/caption/outline presets, full font and outline control, five entrance animations including typewriter
- **Backgrounds**: solid, linear gradient, radial gradient, image, or the blurred clip itself (for landscape footage in a vertical frame)
- **Audio**: per-clip volume, fades, speed and reverse; per-track faders; mixed at 48 kHz stereo on a Web Audio clock so picture and sound cannot drift
- **Preview**: on-canvas transform handles, frame stepping, loop, safe zones, rule-of-thirds grid, PNG frame grab, full screen

### Formats and limits
- **Project sizes**: 4K 3840×2160, 1440p, 1080p, 720p, vertical 1080×1920, portrait 4:5 1080×1350, square 1080×1080, or custom
- **Frame rates**: 23.976, 24, 25, 30, 50, 60 fps
- **Import**: MP4, M4V, MOV, MKV, WebM, MPEG-TS; MP3, WAV, M4A, AAC, FLAC, OGG, Opus, MKA; PNG, JPEG, WebP, GIF, AVIF
- **Export**: MP4 (H.264), MOV, MKV, WebM (VP9) for video; M4A, WAV, OGG for audio only. Four quality levels, measured file-size estimate, optional range-only export
- **Projects**: saved as a single `.nayanproj` file (a zip) containing the timeline and every imported media file
- **Requirements**: a browser with WebCodecs (Chrome/Edge 94+, Safari 16.4+) and a window at least 1024px wide. WebGL2 accelerates the grade and key, with a Canvas2D fallback
- **Not supported**: collaboration, cloud storage, keyframed animation, and timelines larger than the machine's memory

## Best Practices

### Component Design
- Use semantic HTML elements for accessibility
- Provide proper ARIA labels and descriptions
- Support keyboard navigation
- Include loading and error states
- Use consistent spacing and typography

### Performance
- Use React.memo for expensive components
- Implement proper key props for lists
- Avoid inline object creation in render methods
- Use useCallback and useMemo for expensive computations

### Styling
- Use Tailwind utility classes for consistent styling
- Leverage HeroUI design tokens (bg-surface, text-foreground, border-default, etc.)
- Provide className props for component customization
- Use responsive design principles
